1. PROBLEM STATEMENT & PROJECT IDENTITY
================================================================================

PROBLEM STATEMENT (SIH26147):
"Automated Model for Analysis of .IQ and .WAV Files Along with Signal Parameter 
 Extraction"

DOMAIN & CONTEXT:
Radio Frequency (RF) Signal Intelligence (SIGINT), Software Defined Radio (SDR), 
and Automated Modulation Classification (AMC). In defense, spectrum management, 
and electronic warfare, unknown RF signals are intercepted without prior metadata. 
Operators receive raw binary samples (.iq, complex binary) or audio-wrapped captures (.wav) 
and must determine:
  - What sample format and data type are present?
  - What frequencies and bandwidths are being occupied?
  - How many distinct signal emissions exist?
  - What are the symbol rates, frequency deviations, and signal power levels?
  - What modulation scheme is being used (BPSK, QPSK, 8PSK, 16QAM, 64QAM, FSK, AM, FM)?
  - How to demodulate the signal without user-provided parameters (Blind Demodulation)?
  - What Forward Error Correction (FEC) and interleaving schemes are applied?
  - What data or protocol structure lies within the extracted bitstream?

CORE PHILOSOPHY & NON-CLAIMS:
1. 100% Deterministic & Inspectable: Every chart, metric, and confidence score is 
   computed deterministically from signal samples via SciPy/NumPy algorithms. No 
   decorative visuals or fake numbers are ever generated.
2. Honest Uncertainty Handling: If a signal parameter cannot be reliably estimated 
   (e.g., due to low SNR or lack of cyclostationary features), the platform explicitly 
   sets `status="unable"` with `value=null` and attaches the exact reason.
3. Hybrid Decision Engine: AMC uses a composite matrix combining physical DSP rules, 
   measured constellation Error Vector Magnitude (EVM), spectral features, and an 
   optional scikit-learn RandomForest model vote. ML is an optional contributor, 
   never a single point of failure.
4. Session Isolation: All uploads, analyses, and reports are strictly scoped to user 
   browser sessions using `x-session-id` headers.

================================================================================
4. SYSTEM DATA FLOW & ASYNC EXECUTION MODEL
================================================================================

1. CLIENT REQUEST & FILE INGESTION:
   - User drops a `.wav`, `.iq`, or `.cbin` file in the UI.
   - `frontend/src/lib/api.ts` sends `POST /api/upload` with `x-session-id` header.
   - FastAPI (`backend/app/routes/files.py`) streams the body in 64 KB chunks to 
     `data/uploads/<uuid>.<ext>` up to `SIH_MAX_UPLOAD_MB`.
   - `dsp/iqformats.detect_format` reads initial byte chunks, identifies container header 
     or binary structure, and returns a format detection report cached in DB.

2. JOB ENQUEUEING & BACKGROUND THREAD POOL:
   - User initiates analysis (`POST /api/analyze` or `/api/blind-analysis`).
   - `backend/app/jobs.py` creates an `AnalysisSessionRow` in SQLite/PostgreSQL with `status="queued"`.
   - The job is dispatched to a background worker thread (`ThreadPoolExecutor`).
   - The frontend UI immediately receives `{ "job_id": "...", "status": "queued" }` and 
     starts polling `GET /api/jobs/{id}` at 1-second intervals.

3. WORKER PIPELINE EXECUTION (`dsp/pipeline.py`):
   - The worker thread calls `dsp/pipeline.analyse_record`.
   - As each of the 15 pipeline stages executes, the worker updates the job status message 
     (e.g., `spectrum -> spectrogram -> detection -> parameters -> classification...`) 
     and writes progress percentages (0% to 100%).
   - If a specific stage encounters invalid data (e.g. noise-only input), the stage recorder 
     catches the exception, marks `ok=False` for that stage, sets dependent downstream 
     outputs to `status="unable"`, and allows independent stages to continue.

4. CACHING & PERSISTENCE (`backend/app/storage.py` & `db.py`):
   - Upon pipeline completion, queryable summary metrics (SNR, modulation, symbol rate, 
     carrier peak, bitstream stats) are saved into relational SQL tables.
   - The entire complex result dictionary (including decimation vectors for charts, full 
     constellation points, eye traces, and evidence nodes) is JSON serialized, compressed 
     with gzip, and saved to `data/cache/<analysis_id>.json.gz`.
   - The job status changes to `status="done"`.

5. CLIENT RENDERING & REPORT EXPORT:
   - The React UI polling loop detects `status="done"`.
   - The UI fetches `GET /api/analysis/{id}/result` (or individual tab endpoints like 
     `/spectrum`, `/constellation`, `/bitstream`).
   - `Plotly.js` renders interactive charts on the web page.
   - When the user clicks "Export PDF", `backend/app/reports.py` reads the cached result 
     and uses ReportLab to render a multi-page PDF document.


================================================================================
5. ALGORITHMIC & MATHEMATICAL SPECIFICATION OF THE 15 DSP STAGES
================================================================================

--------------------------------------------------------------------------------
STAGE 1: FORMAT & CONTAINER DETECTION (`dsp/iqformats.py`)
--------------------------------------------------------------------------------
- Purpose: Identify binary layout, data type, byte order, and complex channel structure.
- Supported Dtypes (7 types):
  1. `float32`: 32-bit IEEE 754 floating point (-1.0 to +1.0)
  2. `int16`: Signed 16-bit PCM integer (-32768 to +32767)
  3. `int8`: Signed 8-bit integer (-128 to +127)
  4. `uint8`: Unsigned 8-bit offset-binary (0 to 255, zero-point at 128)
  5. `int32`: Signed 32-bit PCM integer
  6. `float64`: 64-bit double precision float
  7. `uint16`: Unsigned 16-bit integer
- Supported Layouts:
  - `interleaved`: I0, Q0, I1, Q1, I2, Q2...
  - `planar`: All I samples followed by all Q samples.
  - `real_only`: Single real channel (e.g. standard audio WAV), converted to complex via Hilbert transform `scipy.signal.hilbert()`.
- Detection Logic:
  - Parses RIFF WAV headers for sample rate (`fmt ` chunk), channels, bit depth.
  - For raw `.iq`/`.cbin`, evaluates statistical distributions (mean, variance, min/max range, zero-crossing rate) across candidate dtypes to determine the correct binary representation with an explicit confidence score.

--------------------------------------------------------------------------------
STAGE 2: PREPROCESSING & SIGNAL CLEANING (`dsp/preprocess.py`)
--------------------------------------------------------------------------------
- DC Bias Removal: Computes complex mean $\mu = \frac{1}{N} \sum x[n]$ and subtracts it: $x_{dc}[n] = x[n] - \mu$.
- Linear Detrending: Fits a least-squares linear trend to I and Q rails independently and subtracts it.
- Power Normalization: Calculates RMS amplitude $A_{rms} = \sqrt{\frac{1}{N} \sum |x[n]|^2}$ and scales signal: $x_{norm}[n] = \frac{x[n]}{A_{rms}}$.
- Filtering:
  - Low-pass / Band-pass / High-pass FIR filters designed via SciPy `scipy.signal.firwin` with Kaiser windowing.
- IQ Imbalance Correction: Estimates phase error $\theta_{err}$ and amplitude error $\alpha_{err}$ between I and Q channels, applying Gram-Schmidt orthogonalization.

--------------------------------------------------------------------------------
STAGE 3: SPECTRUM & POWER SPECTRAL DENSITY (`dsp/spectrum.py`)
--------------------------------------------------------------------------------
- Welch PSD Calculation: Uses `scipy.signal.welch` with segment size $N_{fft} \in [1024, 8192]$, 50% overlap, and Hann windowing:
  $$P(f) = \frac{1}{K} \sum_{k=1}^K |FFT(x_k[n] \cdot w[n])|^2$$
- Noise Floor Estimation: Applies a median / 20th-percentile rolling filter across frequency bins to isolate baseline thermal noise $N_0$.
- Carrier Frequency Peak: Locates frequency $f_c = \arg\max_f P(f)$.
- Occupied Bandwidth (OBW 99%): Integrates cumulative spectral power $\int_{f_1}^{f_2} P(f) df$ and finds lower bound $f_{low}$ and upper bound $f_{high}$ containing 99% of total integrated power. $OBW = f_{high} - f_{low}$.
- Spectral SNR: $SNR_{dB} = 10 \log_{10} \left( \frac{P_{peak} - N_0}{N_0} \right)$.

--------------------------------------------------------------------------------
STAGE 4: WATERFALL SPECTROGRAM (`dsp/waterfall.py`)
--------------------------------------------------------------------------------
- Short-Time Fourier Transform (STFT): Computes time-frequency matrix $S(t, f)$ using `scipy.signal.stft` with configurable hop size and FFT length.
- Visual Decimation: For web display, large matrices (e.g. 10000x2048) are downsampled to bounded dimensions (max 800x400) using max-pooling to preserve transient spectral bursts without lagging the browser.

--------------------------------------------------------------------------------
STAGE 5: MULTI-EMISSION SIGNAL DETECTION (`dsp/detect.py`)
--------------------------------------------------------------------------------
- CFAR (Constant False Alarm Rate) Detector:
  - Slides a frequency window with Guard Cells and Reference Cells across the PSD.
  - Cell-Averaging CFAR (CA-CFAR) computes noise threshold $T = \alpha \cdot P_{ref}$.
  - Smallest-Of CFAR (SO-CFAR) handles closely-spaced adjacent signals by selecting $\min(P_{left}, P_{right})$.
- Emission Grouping: Contiguous frequency bins exceeding threshold $T$ are merged into discrete signal objects with properties: `{start_time, end_time, center_freq, bandwidth, peak_power, snr}`.

--------------------------------------------------------------------------------
STAGE 6: PARAMETER EXTRACTION (`dsp/params.py`)
--------------------------------------------------------------------------------
- Symbol Rate Estimation ($R_s$): Reconciles 3 independent mathematical estimators:
  1. Cyclostationary Spectral Line Extraction: Computes FFT of nonlinear signal transformations $|x[n]|^2$ or $|x[n]|$ and searches for discrete cyclic frequency spectral lines.
  2. Magnitude Autocorrelation Peak Spacing: Computes autocorrelation $R_{xx}[\tau] = \sum |x[n]| |x[n+\tau]|$ and detects periodic peak intervals $\tau_s = 1/R_s$.
  3. Filterbank Wavelet Energy Fluctuations: Computes derivative of envelope energy to isolate symbol transition edges.
  - Reconciled Rate: Weighted median of the 3 estimators. If estimators disagree significantly, reports lower confidence.
- FSK Deviation ($\Delta f$): Analyzes instantaneous frequency histogram $f[n] = \frac{f_s}{2\pi} \frac{d}{dn} \arg(x[n])$ to measure peak frequency separation.
- PAPR (Peak-to-Average Power Ratio): $PAPR_{dB} = 10 \log_{10} \left( \frac{\max |x[n]|^2}{\frac{1}{N} \sum |x[n]|^2} \right)$.

--------------------------------------------------------------------------------
STAGE 7: HYBRID MODULATION CLASSIFICATION (`dsp/modulation.py` & `ml/`)
--------------------------------------------------------------------------------
- Extracted Feature Vector (18 metrics):
  - $\gamma_{max}$: Normalized maximum value of spectral density of centered instantaneous series.
  - $\sigma_{ap}$: Standard deviation of absolute phase centered in non-weak regions.
  - $\sigma_{dp}$: Standard deviation of direct phase.
  - $\sigma_{aa}$: Standard deviation of absolute normalized amplitude.
  - $\mu_{42}^a$: Envelope kurtosis / 4th-order cumulants.
  - $EVM_{PSK/QAM}$: Error Vector Magnitude against standard constellation grids.
- Decision Engine Fusion:
  1. Hard Physical Rules: (e.g. constant amplitude $\implies$ FSK/PSK; discrete phase jumps $\implies$ PSK; two-ring amplitude ratio $\implies$ 16QAM).
  2. EVM Distance Matching: Calculates RMS distance between symbol points and ideal constellation centroids.
  3. ML Classifier Vote: `RandomForestClassifier` outputs probability distribution $P(Mod|Features)$.
  - Composite Confidence: Weighted sum of DSP rule agreement (50%), EVM fit (30%), and ML vote (20%).

--------------------------------------------------------------------------------
STAGE 8: CONSTELLATION & EYE DIAGRAM ANALYSIS (`dsp/modulation.py`)
--------------------------------------------------------------------------------
- Carrier Phase Recovery: Costas loop or M-th power phase locked loop (PLL) tracks residual carrier phase offset $\theta[n]$.
- Symbol Sampling: Samples cleaned complex envelope at optimum timing instant $n_k = k \cdot T_s + \tau$.
- EVM Metrics:
  $$EVM_{RMS} (\%) = \sqrt{ \frac{\frac{1}{M} \sum_{m=1}^M |S_m - \hat{S}_m|^2}{\frac{1}{M} \sum_{m=1}^M |S_{ideal,m}|^2} } \times 100$$
- Eye Diagram Traces: Overlays symbol periods $2 T_s$ wide to visualize zero-crossing jitter and vertical eye opening height.

--------------------------------------------------------------------------------
STAGE 9: BLIND DEMODULATION (`dsp/demod.py`)
--------------------------------------------------------------------------------
- Carrier Synchronization: Costas loop for PSK; M-th power loop for QAM.
- Matched Filtering: Root-Raised Cosine (RRC) filter with roll-off factor $\alpha \in [0.2, 0.35]$.
- Timing Synchronization: Gardner timing error detector (TED) or Mueller-Muller TED adjusts fractional delay interp filter.
- Decision Boundary Slicing: Maps synchronized complex symbols to nearest constellation point bit patterns, outputting hard bits and soft-decision LRs (Log-Likelihood Ratios).

--------------------------------------------------------------------------------
STAGE 10: FEC HYPOTHESIS TESTING (`dsp/fec.py`)
--------------------------------------------------------------------------------
- Candidate Codes Tested:
  - Convolutional Codes: Viterbi decoding with rate $r=1/2, 2/3, 3/4$, constraint length $K=7$, generator polynomials $G_1=171_8, G_2=133_8$.
  - Reed-Solomon Codes: $RS(255, 223)$, $RS(255, 239)$ over $GF(2^8)$.
- Statistical z-score Verification:
  - Decodes bitstream with candidate code, re-encodes, and computes Bit Error Rate (BER) reduction against uncoded control baseline.
  - Computes z-score: $Z = \frac{BER_{uncoded} - BER_{re-encoded}}{\sigma_{baseline}}$.
  - Code hypothesis is ONLY claimed if $Z > 3.0$ (99.7% statistical confidence).

--------------------------------------------------------------------------------
STAGE 11: INTERLEAVING HYPOTHESIS TESTING (`dsp/interleave.py`)
--------------------------------------------------------------------------------
- Candidate Geometries: Matrix Block Interleaver ($R \times C$), Diagonal Interleaver, Convolutional Interleaver.
- Search Strategy: Re-orders bit matrix across candidate dimensions $N \in [2, 128]$.
- Evaluation Metric: Computes bit-matrix dispersion reduction and autocorrelation periodicity enhancement post-deinterleaving.
- Bounded Execution: Enforces time budget `interleave_time_budget_s` (default 2.0s). If budget expires, returns `truncated=True`.

--------------------------------------------------------------------------------
STAGE 12: BITSTREAM DIAGNOSTICS (`dsp/bitstream.py`)
--------------------------------------------------------------------------------
- Shannon Entropy: Computes byte-level entropy:
  $$H(X) = - \sum_{i=0}^{255} p(x_i) \log_2 p(x_i)$$
  - $H \approx 8.0$: High randomness (compressed data, encryption, or raw noise).
  - $H \approx 1.0 - 4.0$: Structured framed data or text.
- Bit Bias Ratio: Ratio of 1s to 0s: $R_{bias} = \frac{N_1}{N_0 + N_1}$.
- Run-Length Distribution: Counts consecutive sequences of identical bits (e.g. 11111).
- Printable ASCII Candidate Extraction: Scans byte stream for contiguous printable ASCII sequences (character codes 32-126) and calculates printable density score.

--------------------------------------------------------------------------------
STAGE 13: PATTERN CORRELATION (`dsp/correlate.py`)
--------------------------------------------------------------------------------
- FFT-Assisted Cross-Correlation: Computes cross-correlation between bitstream and user-supplied sync word / header pattern $P[n]$ using FFT convolution:
  $$R_{xy}[k] = IFFT( FFT(X) \cdot FFT(P)^* )$$
- Preamble Candidate Discovery: Scans bitstream for automatically repeating bit sequences of length $L \in [8, 64]$.

--------------------------------------------------------------------------------
STAGE 14: MULTI-HYPOTHESIS RANKING & EVIDENCE GRAPH (`dsp/hypothesis.py`)
--------------------------------------------------------------------------------
- Multi-Hypothesis Score Formula: Composite score $S_{hyp} \in [0.0, 1.0]$:
  $$S_{hyp} = 0.30 \cdot Q_{demod} + 0.25 \cdot C_{class} + 0.15 \cdot A_{rate} + 0.10 \cdot F_{spec} + 0.10 \cdot D_{const} + 0.10 \cdot E_{agree}$$
  - $Q_{demod}$: Demodulator EVM quality score.
  - $C_{class}$: AMC classifier confidence.
  - $A_{rate}$: Symbol rate estimator agreement score.
  - $F_{spec}$: Spectral occupied bandwidth fit.
  - $D_{const}$: Constellation cluster separation.
  - $E_{agree}$: Independent evidence source agreement count.
- Evidence Graph Construction: Nodes represent pipeline stages (Format, Spectrum, Emission, Rate, Modulation, Demod, FEC, Bitstream). Edges represent data transformation dependencies.

--------------------------------------------------------------------------------
STAGE 15: REPORT GENERATION & PERSISTENCE (`backend/app/reports.py`)
--------------------------------------------------------------------------------
- SQL Database Insert: Writes session metadata to `analysis_sessions` SQL table.
- Cache Storage: Compresses complete analysis dictionary to `data/cache/<analysis_id>.json.gz`.
- Multi-Format Document Exporters:
  - PDF: Multi-page document built with ReportLab containing executive tables, spectral parameters, EVM metrics, evidence graph node states, and limitation notes.
  - JSON: Complete machine-readable hierarchical result tree.
  - CSV: Tabular parameter matrix for importing into Excel/MATLAB.
  - TXT: Plaintext summary report for terminal viewing.

6. MACHINE LEARNING MODULATION CLASSIFIER SUBSYSTEM
================================================================================

Subsystem Location: `ml/`
Training Script: `ml/train_classifier.py`
Artifact: `ml/models/modclass.joblib`

MODEL SPECIFICATION:
- Algorithm: `scikit-learn.ensemble.RandomForestClassifier`
- Estimators: 100 decision trees
- Max Depth: 12
- Feature Vector Size: 18 features (extracted by `dsp/modulation.py`)
- Target Modulation Classes (9 classes):
  `BPSK`, `QPSK`, `8PSK`, `16QAM`, `64QAM`, `2FSK`, `GFSK`, `AM`, `FM`

GRACEFUL DEGRADATION ARCHITECTURE:
- The backend checks for the presence of `ml/models/modclass.joblib` on startup.
- If the file is missing or scikit-learn is uninstalled, the backend automatically degrades to `DSP-only mode`.
- In DSP-only mode, modulation classification runs using physical DSP rules and constellation EVM matching alone, returning a warning in the response: `"ml_model_available": false`.

9. SYNTHETIC GENERATOR & SELF-BENCHMARKING ENGINE
================================================================================

SYNTHETIC SIGNAL GENERATOR (`dsp/synth.py`):
- Generates mathematically precise IQ signals with exact ground truth for validation.
- Configurable Parameters:
  - Modulations: BPSK, QPSK, 8PSK, 16QAM, 64QAM, 2FSK, GFSK, AM, FM.
  - Sample Rate ($f_s$) & Symbol Rate ($R_s$).
  - Pulse Shaping: Root-Raised Cosine (RRC), Raised Cosine (RC), Rectangular, Gaussian (for GFSK).
  - Impairments: AWGN Noise (configurable SNR in dB), Carrier Frequency Offset (CFO in Hz), Phase Noise, Symbol Timing Jitter, Rayleigh/Rician Multipath Fading.
  - Data Payload: Pseudo-Random Binary Sequence (PRBS-9, PRBS-15) or custom ASCII text.
  - FEC / Interleaver: Optional Convolutional encoding and block matrix interleaving.
- Ground Truth File (`GROUND_TRUTH.json`): Saves exact parameters alongside generated files for 100% verifiable evaluation.

AUTOMATED BENCHMARKING ENGINE (`dsp/benchmark.py`):
- Runs automated AMC classification benchmarks across multiple modulations and SNR steps (e.g., -5 dB to +20 dB).
- Evaluates classification accuracy against synthetic ground truth.
- Generates a 2D Confusion Matrix (True Modulation vs Predicted Modulation).
- Results displayed interactively in `Benchmark.tsx`.
